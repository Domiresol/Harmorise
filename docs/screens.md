> **프로젝트:** Harmorise
> **작성팀:** 기획팀
> **버전:** v1.0
> **작성일:** 2026년 5월 23일

---

## 1. 화면 구조 개요

```
(비회원)
  /                    → 랜딩 페이지
  /login               → 로그인
  /signup              → 회원가입

(신규 회원)
  /onboarding          → 온보딩 (악기·목표 설정)

(회원 — 하단 탭 네비게이션)
  /home                → 홈 (대시보드)
  /practice            → 연습 기록 목록
    /practice/new      → 연습 기록 작성
    /practice/:id      → 연습 기록 상세
    /practice/:id/edit → 연습 기록 수정
  /bpm                 → BPM 관리 목록
    /bpm/:songId       → BPM 상세 (곡별 성장 그래프 + 연습 기록 탭)
  /songs               → 내 연습곡 목록 (전체 곡 / BPM 기록 있는 곡 필터)
  /calendar            → 연습 캘린더
  /report              → 리포트 목록
    /report/weekly/:id → 주간 리포트 상세
    /report/monthly/:id→ 월간 리포트 상세
  /memo                → 메모 목록
  /settings            → 설정 홈
    /settings/profile  → 프로필 설정 (닉네임, 자기소개, 프로필 이미지)
    /settings/notifications → 알림 설정
    /settings/account  → 계정 관리

(회원 — 커뮤니티)
  /community                        → 커뮤니티 허브
    /community/friends              → 친구 목록 + 요청 탭
    /community/friends/search       → 친구 검색
    /community/friends/:userId      → 친구 프로필
    /community/rooms                → 연습 방 목록
    /community/rooms/new            → 방 만들기
    /community/rooms/:roomId        → 방 상세 (피드 / 멤버 탭)
    /community/rooms/:roomId/settings → 방 관리 (방장 전용)
```

### SCR-004 · 온보딩 `/onboarding`

| 항목 | 내용 |
|------|------|
| 접근 권한 | 신규 회원 (온보딩 미완료) |
| Phase | MVP |

**구성 요소 (스텝 형식, 총 3단계)**

*Step 1 — 악기 선택*
- 악기 목록 그리드 (아이콘 형태): 기타, 베이스, 피아노, 드럼, 바이올린, 보컬, 기타(직접입력)
- 복수 선택 가능, 대표 악기 1개 지정

*Step 2 — 연습 목표 설정*
- 일일 목표 연습 시간 (슬라이더: 15분 단위, 15분~4시간)
- 주간 목표 연습 일수 (슬라이더: 1~7일)

*Step 3 — 캐릭터 선택*
- 기본 캐릭터 타입 선택 (HUMAN / ANIMAL / ROBOT)
- 닉네임 입력

**동작**
- 각 스텝 하단 "다음" 버튼, 진행 바 표시
- 완료 시 홈으로 이동

### SCR-024 · 연습방 목록 `/community/rooms`

| 항목 | 내용 |
|------|------|
| 상단 | 초대코드 입력 섹션 (토글) |
| 목록 | 방 이름, 설명, 멤버 수, 방장 뱃지 |
| 우상단 | 방 만들기 버튼 → SCR-025 |

---

### SCR-025 · 방 만들기 `/community/rooms/new`

| 항목 | 내용 |
|------|------|
| 입력 | 방 이름 (최대 20자), 설명 (선택, 최대 100자) |
| 제출 | 방 생성 → 방 상세 페이지로 이동 |

---

### SCR-026 · 방 상세 `/community/rooms/:roomId`

| 항목 | 내용 |
|------|------|
| 탭 | 피드 / 멤버 |
| 초대코드 카드 | 방장에게만 표시. 복사 버튼 포함 |
| 피드 탭 | 멤버 연습 기록: 닉네임, 악기, 곡, BPM, 경과 시간. 메모 비공개 |
| 멤버 탭 | 멤버 목록: 닉네임, @handle, 이번 주 연습 일수. 방장 뱃지 |
| 우상단 | 방장만 관리 버튼 → SCR-027 |

---

### SCR-027 · 방 관리 `/community/rooms/:roomId/settings`

| 항목 | 내용 |
|------|------|
| 권한 | 방장 전용 |
| 기능 | 방 이름/설명 수정, 초대코드 재발급, 멤버 강퇴, 방장 위임, 방 삭제 |
| 입장 요청 | 대기 중인 입장 요청 목록: 수락 / 거절 버튼 |
