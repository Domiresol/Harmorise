## 1. 문서 개요

### 1.1 목적

본 문서는 Harmorise 서비스의 기능을 상세하게 정의하고, 개발팀·디자인팀이 공통된 기준으로 구현할 수 있도록 작성된 기능 명세서이다.

### 1.2 범위

- 웹 앱 기준으로 작성 (WebView 앱은 동일 기능 적용)
- 지원 화면: 모바일 세로 (~ 767px), 태블릿 가로 (768px ~)
- MVP(1차 출시) 기능과 추후 확장 기능을 구분하여 명시

### 1.3 용어 정의

| 용어 | 정의 |
|------|------|
| 연습 세션 | 사용자가 한 번 기록하는 연습 단위 |
| BPM | Beats Per Minute. 음악 템포 단위 |
| 스트리크 | 연속 연습 일수 |
| 리포트 | 기간별 연습 데이터 요약 통계 |

## 3. 공통 기능

### 3.1 회원가입 / 로그인

| 항목 | 내용 |
|------|------|
| 기능 ID | AUTH-001 |
| 우선순위 | 필수 (MVP) |

**기능 설명**
- 이메일 + 비밀번호 회원가입
- 소셜 로그인 지원: 카카오, 구글, 애플
- 로그인 상태 유지 (자동 로그인)
- 비밀번호 찾기 / 재설정

**규칙**
- 이메일 중복 가입 불가
- 비밀번호: 영문+숫자+특수문자 조합 8자 이상
- 로그인 5회 실패 시 30분 잠금

## 4. 연습 기록 기능

### 4.1 연습 세션 기록

| 항목 | 내용 |
|------|------|
| 기능 ID | PRACTICE-001 |
| 우선순위 | 필수 (MVP) |

**기능 설명**
사용자가 연습한 내용을 기록하는 핵심 기능. 빠른 입력을 최우선으로 설계한다.

**입력 항목**

| 필드 | 타입 | 필수 여부 | 설명 |
|------|------|-----------|------|
| 연습 날짜 | Date | 필수 | 기본값: 오늘 날짜 |
| 연습 시간 | Number (분) | 필수 | 슬라이더 또는 직접 입력 |
| 악기 | Select | 필수 | 온보딩에서 설정한 악기 기본 선택 |
| 연습 곡 | Text | 선택 | 곡명 텍스트 입력, 최근 기록에서 자동완성 |
| 연습 유형 | Multi-select | 선택 | 기초 연습 / 곡 연습 / 즉흥 연주 / 이론 학습 |
| BPM | Number | 선택 | 해당 곡의 목표/달성 BPM |
| 메모 | Textarea | 선택 | 자유 텍스트 |

**동작 규칙**
- 연습 시간 최솟값: 1분, 최댓값: 720분(12시간)
- 연습 세션은 하루에 여러 개 기록 가능
- 저장 시 Kafka 이벤트 발행 → TimescaleDB 적재 및 리포트 집계 트리거
