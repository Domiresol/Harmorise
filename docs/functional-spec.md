## 1. 문서 개요

### 1.1 목적

본 문서는 Harmorise 서비스의 기능을 상세하게 정의하고, 개발팀·디자인팀이 공통된 기준으로 구현할 수 있도록 작성된 기능 명세서이다.

### 1.2 범위

- 웹 앱 기준으로 작성 (WebView 앱은 동일 기능 적용)
- 지원 화면: 모바일 세로 (~ 767px), 태블릿 가로 (768px ~)
- MVP(1차 출시) 기능과 추후 확장 기능을 구분하여 명시

### 1.3 용어 정의

| 용어 | 정의 |
|------|------|
| 연습 세션 | 사용자가 한 번 기록하는 연습 단위 |
| BPM | Beats Per Minute. 음악 템포 단위 |
| 스트리크 | 연속 연습 일수 |
| 리포트 | 기간별 연습 데이터 요약 통계 |

## 3. 공통 기능

### 3.1 회원가입 / 로그인

| 항목 | 내용 |
|------|------|
| 기능 ID | AUTH-001 |
| 우선순위 | 필수 (MVP) |

**기능 설명**
- 이메일 + 비밀번호 회원가입
- 소셜 로그인 지원: 카카오, 구글, 애플
- 로그인 상태 유지 (자동 로그인)
- 비밀번호 찾기 / 재설정

**규칙**
- 이메일 중복 가입 불가
- 비밀번호: 영문+숫자+특수문자 조합 8자 이상
- 로그인 5회 실패 시 30분 잠금

## 4. 연습 기록 기능

### 4.1 연습 세션 기록

| 항목 | 내용 |
|------|------|
| 기능 ID | PRACTICE-001 |
| 우선순위 | 필수 (MVP) |

**기능 설명**
사용자가 연습한 내용을 기록하는 핵심 기능. 빠른 입력을 최우선으로 설계한다.

**입력 항목**

| 필드 | 타입 | 필수 여부 | 설명 |
|------|------|-----------|------|
| 연습 날짜 | Date | 필수 | 기본값: 오늘 날짜 |
| 연습 시간 | Number (분) | 필수 | 슬라이더 또는 직접 입력 |
| 악기 | Select | 필수 | 온보딩에서 설정한 악기 기본 선택 |
| 연습 곡 | Text | 선택 | 곡명 텍스트 입력, 최근 기록에서 자동완성 |
| 연습 유형 | Multi-select | 선택 | 기초 연습 / 곡 연습 / 즉흥 연주 / 이론 학습 |
| BPM | Number | 선택 | 해당 곡의 목표/달성 BPM |
| 메모 | Textarea | 선택 | 자유 텍스트 |

**동작 규칙**
- 연습 시간 최솟값: 1분, 최댓값: 720분(12시간)
- 연습 세션은 하루에 여러 개 기록 가능
- 저장 시 Kafka 이벤트 발행 → TimescaleDB 적재 및 리포트 집계 트리거

> Gemini API 기반 자연어 피드백 + Basic Pitch/Librosa 객관 지표 조합

### 13.1 기능 개요

| 항목 | 내용 |
|------|------|
| 기능 ID | EVAL-001 |
| 우선순위 | Phase 4 |

---

### 13.2 핵심 기능

#### EVAL-001 · 연주 녹음 및 업로드

- 연습 기록 화면 내 녹음 버튼으로 연주를 직접 녹음
- S3(또는 Cloudflare R2)에 직접 업로드 (Presigned URL 방식)
- 허용 포맷: audio/webm, audio/mp4, audio/wav
- 최대 길이: 5분 / 최대 크기: 50MB
- 연습 세션과 연결하거나 독립 녹음으로 저장 가능

#### EVAL-002 · 객관 지표 분석 (Basic Pitch + Librosa)

레퍼런스(악보/정답) 없이 녹음 자체를 분석하여 제공:

| 지표 | 설명 | 비고 |
|------|------|------|
| BPM 일관성 | 연주 중 박자가 일정하게 유지되었는지 (0-100) | 전 악기 |
| 분당 음 수 | 연주 밀도 | 전 악기 |
| 최장 연속 연주 | 중단 없이 연속으로 연주한 최대 시간 (초) | 전 악기 |
| 리듬 정확도 | 박자 시작점 기반 정확도 (0-100) | 전 악기 |
| 피치 정확도 | 단선율 악기만 측정 (보컬/플루트/트럼펫 등) | 코드 악기는 null |

> **설계 원칙:** 드럼은 피치 없음 → BPM/리듬 지표만 제공. 기타/피아노 코드는 피치 정확도 null로 처리.

#### EVAL-003 · AI 자연어 피드백 (Gemini API)

- 레퍼런스 없이도 즉흥 연주 포함 모든 연주에 피드백 제공
- 악기 종류, 연습 유형(즉흥/곡 연습 등)을 컨텍스트로 함께 전달
- 피드백 예시:
  - "전반적으로 박자가 안정적이에요. 중간 부분에서 템포가 약간 빨라지는 경향이 있어요."
  - "즉흥 연주치고 스케일 선택이 일관성 있어요. 다이나믹 변화를 더 주면 표현력이 풍부해질 것 같아요."
- 응답 시간: 녹음 제출 후 약 10~30초 (비동기 처리)
- 언어: 한국어

---

### 13.3 처리 흐름

```
① 사용자 녹음 종료
        ↓
② Presigned URL 요청 → S3 직접 업로드
        ↓
③ 서버에 업로드 완료 알림 → BullMQ 잡 등록
        ↓
④ [Worker] Basic Pitch + Librosa → 객관 지표 추출
        ↓
⑤ [Worker] Gemini API → 자연어 피드백 생성
        ↓
⑥ 결과 저장 → 사용자에게 노출 (폴링 또는 SSE)
```

---

### 13.4 프리미엄 연계

- 현재: 전체 사용자 무료 제공으로 시작, 실제 사용량 파악 후 제한 여부 결정
- 향후 검토: 월 N회 또는 총 M분 초과 시 프리미엄 전용 전환
- Gemini API 비용은 `ai_analysis_jobs.tokens_used` / `audio_seconds` 컬럼으로 추적 중
